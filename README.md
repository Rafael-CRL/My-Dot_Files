# My-Dot_Files

Configurações do meu ambiente Linux.

| Pasta | Ferramenta |
| --- | --- |
| `.zshrc`, `starship.toml` | Zsh e prompt Starship |
| `nvim` | Neovim com LazyVim |
| `kitty`, `alacritty` | Terminais |
| `rofi` | Launcher |
| `mpv` | Player de vídeo, com uosc |
| `neofetch` | Informações do sistema |

Instalação: copiar cada pasta para `~/.config/`, `starship.toml` para `~/.config/` e `.zshrc` para `~/`.
